# StaleDocs 0.5.0-beta.2

Status: Prerelease

## What changed for users

`staledocs audit` and the `audit_documentation` MCP tool report far fewer
false findings. On 20 public repositories (14 popular TypeScript, JavaScript,
and Python projects plus the evaluation corpus repositories), `0.5.0-beta.1`
reported 720 findings and this release reports 21; the per-repository table
and the commits measured are in
[pull request #96](https://github.com/mr-min-max/staledocs/pull/96).

- Links: a directory link with a trailing slash, an extensionless page link
  (`./api-hmr`), and an `.html` page link resolve to the directory or the
  Markdown page.
- Paths: a line suffix or anchor (`src/client.ts:878-898`, `#L10-L20`,
  `guide.md#usage`) is dropped before the lookup, code-span paths resolve
  against every workspace and Python package directory, and a bare folder
  name such as `lib/` is not checked.
- Scripts: a script declared by any workspace package counts; dependency and
  workspace bins run through pnpm, yarn, or bun (`pnpm tsx`, `pnpm tsc`) and
  files run through bun are not scripts; built-in commands such as
  `pnpm patch` are not scripts; a name that continues into a placeholder
  (`pnpm server:<name>`) is skipped. `npm run` and `pnpm run` still need a
  script.
- Release notes (`release-notes.md`) and translated copies of existing pages
  (`docs/ja/`, `docs/zh-hant/`) are skipped.
- In `docs/`, `doc/`, `documentation/`, `guide/`, and `guides/`, a code
  example's missing path or script is reported only with a rename signal: a
  file of the same name elsewhere, or a script within two edits. Links there,
  and root, package, and agent instruction files, keep every rule.
- The audit reads up to 1,000 `package.json` manifests instead of the first
  50, and sets the optional `ignored.manifestLimitReached` past that bound.

`aidoc.audit.v1` keeps its identity; `manifestLimitReached` is optional and
additive. `review`, `check`, the MCP fix path, and the Action are unchanged,
so the evaluation results recorded for `0.5.0-beta.1` in
[`docs/EVALUATIONS.md`](../EVALUATIONS.md) still describe them.

See [RELEASING.md](../RELEASING.md) for the procedure.
